# A node step needs the ceiling hit in two sessions, a parameter step needs one

Before the target moves to the next node on a chain, the last two sessions on the current node
must both have hit the rail's ceiling on every set with the parameter at its limit; one session
is enough for a parameter step. A node step is the expensive move (a new movement, a rep drop, a
new rail) and a single good day proves less than repeatability does, whereas a parameter step is
cheap and reversible. We rejected a single-session gate for nodes because a one-off peak would
push you up the chain and straight back down.
