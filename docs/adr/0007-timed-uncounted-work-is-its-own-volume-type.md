# Timed uncounted work is its own volume type, distinct from a hold

Dynamic work done as an arbitrary AMRAP for a duration, reps not counted, is a **timed** volume
(seconds), separate from a **hold** (an isometric, also seconds) and from **reps** (a counted set).
The owner logs this way and doesn't count, so we can't turn it into reps; and a 30 s AMRAP and a
30 s hold on the same node are different efforts that progress differently, so folding them into
one "time" type would make the history lie. The cost is a third type and no comparison between a
timed and a reps performance, which is honest: there isn't one.
