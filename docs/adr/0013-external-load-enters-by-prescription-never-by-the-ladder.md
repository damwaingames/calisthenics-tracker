# External load enters by prescription, never by the target ladder

Load (a vest, a dip belt, a backpack) goes on a placement in the program by your choice; the
target never adds it on its own, and a loaded placement's ladder is volume then load, stepping
to the next value your equipment offers (a vest's blocks, the plates you own), exactly as a
parameter steps (ADR-0010). Load never steps the node: a loaded placement is a deliberate fork
off the chain, and the chain's own frontier waits for you. We rejected an automatic "chain
exhausted, add weight" rule because whether to load a node or keep climbing the chain is a
training decision, not something the app can infer, and putting it in the ladder would make the
chain's last node behave differently from every other one.
